#General Push/Commit Rules
  1. When you edit a file, on most code editors, the file will show as "untracked"
  2. In order to track these files, do 'git add .' This will ensure you commit all files, BESIDES what is in .gitignore
  3. If you want to commit individual files, do 'git -add -a [file names, separated by commas] (not recommended if gitignore is present)
  4. In order to 'commit' --> do git commit -m 'DESCRIPTION OF CHANGES/FILES ADDED'
  5. If there are any 'merge conflicts', usually the fixes are 'git rebase', or 'git origin main' then commit and push again
  6. Always make sure your local machine is updated with Github with 'git origin main'
